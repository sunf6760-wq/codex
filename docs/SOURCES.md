# 来源规范

## 证据优先级

1. 官方 release/changelog、官方代码仓库 release、官方模型公告：确认发布内容和版本。
2. 官方产品文档、价格页、模型目录、下载页、支持说明：确认当前条件、计费和可用范围。
3. 官方论坛或已从官网确认身份的官方账号：补充逐步开放与限制；不能用含糊宣传替代明确价格。
4. 媒体、社区、自媒体和聚合站：仅作线索，放入待核实；相互转载不构成多份独立证据。

价格、免费额度及平台支持优先核对对应官方条件页。官方来源相互冲突时，保留两者、记录日期和适用范围；冲突未解决的结论留待核实。自行实测只证明该环境/账号的结果。

## 每条来源的格式

```markdown
- S1：[页面标题]({{具体页面永久链接}})
  - 发布者：官方主体
  - 发布/更新日期：YYYY-MM-DD 或未知
  - 访问日期：YYYY-MM-DD
  - 支持结论：明确指出它支持哪项变化和哪些适用条件
  - 定位/留证：版本号、页内小节、release tag 或简短摘录；无则说明
```

链接直接指向具体发布条目或条件页，不使用搜索结果、短链、首页替代已找到的证据。优先永久链接；清除追踪参数，保留决定版本/地区/套餐的参数和定位锚点。

## 可变页面与失效来源

- 价格页、额度页可能没有发布日期：写“未知”，记录访问日期和关键数值；未见变更证据时只称“核查时的状态”，不推定本周发生变化。
- 首次检查只可建立基线，除非来源能证明是本周事件；基线条目标明“基线”，不计入本周新增。
- 对关键可变条款，可在事件中保留必要的短摘录或公开页面截图；不得提交账号信息、密钥、个人账单或完整付费内容。
- 页面消失后保留原 URL、原核查日期及摘要，标注失效并寻找官方替代来源。来源失效本身不抹除历史，也不自动证明原结论错误。
- 只写实际打开并检查过的来源；访问受阻时记录障碍并保留待核实，不把检索摘要当作原文。
