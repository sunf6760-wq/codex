# 字段定义

所有正文使用中文；日期为 `YYYY-MM-DD`，时间使用带时区的 ISO 8601，例如 `2026-10-27T18:00:00+08:00`。未知值写“未知”，不适用写“不适用”，模板占位符必须在发布前替换。无证据时不得估算日期、额度或价格。

## 周报字段

| 字段 | 定义 |
| --- | --- |
| 周号 / 统计窗口 | ISO 周号及上海时区周一至周日；首次初始化可在周中开始 |
| 维护者 / 更新时间 | 实际维护者及最后编辑时间 |
| 核查截止时间 | 实际查证截止点；未开始时写“未开始” |
| 周报状态 | 待检查 / 进行中 / 已完成；已完成表示六维覆盖已交代，允许保留待核实事项 |
| 覆盖表 | 每格只能写：未检查 / 已查有变 / 已查无已核实变化 / 待核实 / 不适用（附理由） |
| 检查日志 | 工具、维度、实际检查时间、直接来源、结果或访问障碍；每个已检查格必须有日志依据，可合并多维 |
| 本周摘要 | 只引用已核实事件；没有核实时明确写“尚无已核实条目” |

## 事件字段

每个事件块保留以下字段。一个事件可有多个维度，归于一个主要工具。

| 字段 | 必填规则与含义 |
| --- | --- |
| 事件 ID | 必填，`E-YYYYMMDD-tool-NN`；日期为首次录入日，tool 为 cursor / trae / claude-code / codex / deepseek；NN 为同工具同日递增序号。分配后不改、不复用 |
| 工具 / 产品形态 | 必填，列出具体产品、CLI/编辑器/桌面/网页/API/模型等 |
| 维度 | 必填，多选：功能 / 模型接入 / Mac支持 / 免费额度 / API定价 / 模型上线 |
| 标题与变化 | 必填，用“原状态 → 新状态”；原状态未知时直写未知，不能补造对比 |
| 去重键 | 必填，`工具\|产品形态\|事件对象\|版本或生效日\|适用范围`；日期未知可用公告标识，不用“未知”笼统合并不同事件 |
| 公告日期 / 生效日期 | 必填，可分别未知；保留来源原时区，跨周归属按上海时间。公告日期不能代替生效日期 |
| 首次发现 / 最后核查 | 必填，实际时间；首次发现不等于发布日期 |
| 核实状态 | 已核实 / 待核实 / 已撤回；已核实至少需要一条直接支持结论的官方证据 |
| 开放状态 | 仅公告 / 候补名单 / 限量或逐步开放 / 预览或测试 / 正式可用 / 已下线 / 未知；不能从核实状态推断 |
| 适用范围 | 必填，版本、套餐、地区、账号、平台及限制；未知逐项标明 |
| 专项详情 | 条件必填，按下表补全；不适用写明 |
| 来源 | 必填，链接、发布者、标题、发布日期（可未知）、访问日期及支持的具体结论；模板包含可复制格式 |
| 证据摘要 | 必填，简短转述证据；自行实测标明环境、日期和复现步骤，不能替代官方普遍可用性证明 |
| 影响 | 必填，面向使用者说明实际变化，推断须标注“判断” |
| 关联与后续 | 关联事件 ID、历史周报链接、待验证问题及下一步；没有则写无 |
| 更正记录 | 无则写无；更正时填日期、旧结论、新结论、原因与新增证据 |

## 专项详情

| 维度 | 需要补充的内容 |
| --- | --- |
| 功能 | 功能名、版本、使用入口、权限/套餐限制 |
| 模型接入 | 完整模型名或 ID、提供方、宿主工具、接入方式（内置/BYOK/第三方）、可用套餐；不等同于模型首次发布 |
| Mac支持 | CLI/网页/原生应用等形态；Intel/Apple Silicon；最低 macOS；安装/下载入口；发布渠道和限制 |
| 免费额度 | 套餐、额度数值、单位、重置周期、试用期限、地区、超额行为及活动有效期；区分长期免费与限时赠送 |
| API定价 | 提供方、模型 ID、官方直连/第三方、币种、计费单位、输入/输出、缓存命中/写入/未命中、批处理等适用费率、生效日；来源未列的项写未披露 |
| 模型上线 | 模型全名、版本/别名、发布方、公告日、各渠道实际可用日、地区、预览/正式状态；权重开放、网页上线、API 上线分别写明 |

价格优先保留来源原单位；如统一为每百万 token，必须同时保留原价及换算式。来源未说明税费、汇率或缓存规则时，不自行添加假设。非 token 计费保留其原单位。
